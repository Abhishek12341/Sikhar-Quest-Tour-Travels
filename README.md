# Sikhar Quest Tour & Travels

A simple, premium and GitHub Pages-ready static travel website.

## Files
- index.html
- css/style.css
- js/script.js

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
1. Upload all files/folders to your repository root.
2. Go to Settings → Pages.
3. Choose Deploy from branch.
4. Select `main` and `/ (root)`.
5. Save.
